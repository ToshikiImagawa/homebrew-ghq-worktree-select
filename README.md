# Homebrew Tap for ghq-worktree-select

Homebrew tap for [ghq-worktree-select](https://github.com/ToshikiImagawa/ghq-worktree-select)

## インストール

```bash
brew install ToshikiImagawa/ghq-worktree-select/ghq-worktree-select
```

## 説明

ghq管理下のリポジトリからブランチを選択してgit worktreeを作成・移動するシェルユーティリティ

詳細は [ghq-worktree-select](https://github.com/ToshikiImagawa/ghq-worktree-select) をご覧ください。
